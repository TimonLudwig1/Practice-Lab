## 🎯 Project Goal
Build a discrete-event simulation of a walk-in clinic with SimPy, then use it the way an analyst would: quantify waiting times, find the bottleneck, and evaluate staffing scenarios with proper statistical care.

## 📊 Dataset Description
No external dataset — the "data" is generated by your simulation. System to model:

- Patients arrive at a walk-in clinic, ~12 per hour on average (Poisson arrivals → exponential inter-arrival times)
- Flow: **registration desk** (1 clerk, ~3 min service) → **treatment room** (doctors, ~15 min service, right-skewed) → 20% need a **lab test** (1 lab station, ~10 min) and then return to see a doctor again briefly
- Clinic is open 8 hours; patients already inside are still served after closing

The notebook contains a minimal SimPy snippet (environment + one resource) as a starting point.

## 💡 Suggested Approach (high-level)
1. Get the minimal example running so you understand `env.process`, `env.timeout`, `Resource.request`.
2. Model the full patient flow as a generator function; collect per-patient timestamps (arrival, queue entry/exit per station, departure) into a list of dicts → DataFrame.
3. Decide on warm-up handling and run length; simulate with 2 doctors as the base case.
4. Replicate: run ~30+ independent replications with different seeds and report **means with confidence intervals** — single-run results in queueing systems are noise.
5. Analyze: distribution of total time in clinic, waiting time per station, resource utilization. Where is the bottleneck? Visualize queue length over the day (matplotlib).
6. Scenario comparison: 2 vs 3 doctors, and 1 extra registration clerk vs 1 extra doctor — which intervention buys more waiting-time reduction per added staff member?
7. Sanity-check one simplified configuration against M/M/c queueing formulas if you want a stretch goal.

## 🏁 Success Criteria
- Working simulation of the full flow including the 20% lab loop
- Results reported over ≥30 replications with 95% CIs (never from a single run)
- Bottleneck identified with evidence (utilization + queue lengths)
- A clear recommendation: which staffing change is most effective, backed by numbers and at least two figures

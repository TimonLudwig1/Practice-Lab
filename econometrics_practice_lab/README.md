# Applied Data Science Lab: Econometrics

Dieses Repository enthält 50 eigenständige, reproduzierbare Übungsprojekte zu Statistik, Regression, Kausalität, Paneldaten, Differences-in-Differences und Instrumental Variables.

## Einstieg

1. In [`topics.md`](topics.md) ein Konzept auswählen.
2. Den passenden Projektordner in der [`Übungsübersicht`](exercises/README.md) öffnen.
3. Zuerst die Aufgaben im Projekt-`README.md` bearbeiten und `starter.py` ergänzen.
4. Anschließend Ergebnisse mit `solution.py` vergleichen.
5. Den Gesamtstand in [`progress.md`](progress.md) nachsehen.

## Installation

```bash
python3 -m pip install -r requirements.txt
```

Alle Datensätze werden mit festen Zufallsseeds lokal erzeugt. Die geprüften Lösungen speichern Daten, Ergebnistabellen und Diagnosegrafiken im jeweiligen Projektordner.

## Umfang

- 50 Topics in neun aufeinander aufbauenden Abschnitten
- 50 Aufgabenstellungen mit Startercode und Musterlösung
- reproduzierbare simulierte Daten ohne externen Download
- numerische Selbstprüfungen und interpretierbare Visualisierungen
- zentraler, nach jeder Übung gepflegter Fortschrittstracker
